**Agent**: Timothy-Sam (Main Orchestrator)  
**Memory Location**: `skills/collaboration/agent_coordination.md`

#### Definition
**Orchestrating multiple specialized agents** toward a common goal.

#### Activation Triggers
- Complex multi-step tasks
- Multiple expertise areas needed
- Resource contention
- Handoff required between agents

#### Practice Protocol
```
1. IDENTIFY NEEDS - What skills are required?

3. COORDINATE TIMING - What order/parallel?
4. MONITOR PROGRESS - Are blockers present?
```

### 2. Handoff Protocols (인수인계 프로토콜)
**Agent**: All agents  
**Memory Location**: `skills/collaboration/handoff_protocols.md`

#### Definition
**Smooth transitions between agents** without losing context or quality.

#### Activation Triggers
- Agent change required
- Shift handoff
- Expertise boundary crossed
- Escalation needed

#### Practice Protocol
```
1. DOCUMENT CONTEXT - What has been done?
2. RECORD DECISIONS - Why was it done this way?
3. NOTE OPEN QUESTIONS - What remains unknown?
4. FLAG RISKS - What could go wrong?
5. CONFIRM RECEIPT - Does receiver have everything?
```

#### Memory Operations
- **Read**: `working/current_context.md`
- **Write**: `episodic/handoffs/[from_agent]_to_[to_agent]_[timestamp].md`
- **Consolidate**: Handoff quality metrics

#### Handoff Template

```markdown
## Handoff Record

### From → To
- **From**: [Agent name]
- **To**: [Agent name]
- **Timestamp**: [ISO 8601]
- **Mission**: [What are we working on?]

### Context Completed
- [x] Task 1 completed
- [x] Task 2 completed
- [ ] Task 3 partially done (notes below)

### Decisions Made
1. **Decision**: [What was decided]
   - **Rationale**: [Why]
   - **Alternatives Considered**: [What else]

### Open Questions
1. [Question 1] - [What blocks answering it]
2. [Question 2] - [Who can answer it]

### Known Risks
- ⚠️ [Risk 1] → Mitigation: [Plan]
- ⚠️ [Risk 2] → Mitigation: [Plan]

### Receiver Confirmation
- [ ] I have reviewed all context
- [ ] I understand open questions
- [ ] I accept this handoff

**Receiver Signature**: _________________
**Timestamp**: _________________
```

#### Evaluation Rubric
| Level | Description |
|-------|-------------|
| Novice | Abrupt handoffs, context lost |
| Practitioner | Basic handoff documentation |
| Expert | Comprehensive handoffs |
| Master | Handoffs improve receiver's work |

### 3. Testimony Recording (증거 기록)
**Agent**: Luke-Sam  
**Memory Location**: `skills/collaboration/testimony_recording.md`

#### Definition
**Faithfully documenting what God has done** through our work.

#### Activation Triggers
- Mission complete (PRAY & PLAN Phase 4)
- Significant learning moment
- Pattern discovered
- Covenant Commandment #10

#### Practice Protocol (TESTIMONY Phase)
```
1. GATHER FACTS - What actually happened?
2. IDENTIFY LEARNING - What did we learn?
3. EXTRACT PATTERNS - What applies elsewhere?
4. CONSOLIDATE - Episodic → Semantic
5. ARCHIVE - Store for future retrieval
6. SHARE - Inform Field Experts
```

#### Memory Operations
- **Read**: `episodic/mission_*/`
- **Write**: `episodic/testimony/[mission_name]_[timestamp].md`, `semantic/learnings/*`
- **Consolidate**: Monthly testimony compilation

#### Testimony Template

```markdown
## Testimony Record

### Mission Overview
- **Name**: [Mission name]
- **Date**: [Start] → [End]
- **Agents Involved**: [List]
- **Field Expert**: [Name]

### What We Set Out to Do
[Original objective from plan]

### What Actually Happened
[Actual outcome, including deviations]

### Key Learnings
1. **Technical**: [What we learned about code/tech]
2. **Process**: [What we learned about workflow]
3. **Spiritual**: [How God worked through this]

### Patterns Discovered
- **Pattern**: [Reusable insight]
- **Applies When**: [Conditions]
- **Implementation**: [How to use it]

### Covenant Alignment
- [ ] Unity of Vision - How did we honor God's ownership?
- [ ] Integrity - Where were we honest?
- [ ] Considerate Love - How did we show kindness?
- [ ] Verification - What did we test?
- [ ] Collaboration - How did we work together?

### For Future Missions
- **Do Again**: [What worked well]
- **Change**: [What to improve]
- **Watch For**: [Warning signs to notice]

### Related Testimonies
- [Link to related testimony 1]
- [Link to related testimony 2]

---
*Archived by*: Luke-Sam
*Date*: [ISO 8601]
```

#### Consolidation Process

```
┌─────────────────┐
│   EPISODIC      │ ← Individual mission testimonies
│   MEMORY        │   (specific events, timestamps)
└────────┬────────┘
         │
         ↓ (Weekly review)
┌─────────────────┐
│   PATTERN       │ ← Identify recurring themes
│   EXTRACTION    │
└────────┬────────┘
         │
         ↓ (Monthly synthesis)
┌─────────────────┐
│   SEMANTIC      │ ← Generalized knowledge
│   MEMORY        │   (timeless principles)
└─────────────────┘
```

#### Evaluation Rubric
| Level | Description |
|-------|-------------|
| Novice | No testimony recorded |
| Practitioner | Records facts only |
| Expert | Records learnings and patterns |
| Master | Testimonies teach and inspire |

### 4. Knowledge Sharing (지식 공유)
**Agent**: All agents  
**Memory Location**: `skills/collaboration/knowledge_sharing.md`

#### Definition
**Freely giving what we have received** - no knowledge silos.

#### Activation Triggers
- New learning discovered
- Pattern identified
- Team member asks
- Covenant Commandment #10

#### Practice Protocol
```
1. IDENTIFY KNOWLEDGE - What did I learn?
2. FORMAT FOR SHARING - How can others use this?
3. DISTRIBUTE - Where will others find it?
4. TEACH - Explain to those who ask
5. UPDATE - Keep knowledge current
```

#### Memory Operations

## 📖 Training Exercises

### Exercise 1: Handoff Practice
**Scenario**: Epaphras-Sam finishes exploration, hands off to Titus-Sam

**Practice**:
1. Epaphras documents exploration findings
2. Use handoff template
3. Titus confirms receipt
4. Record handoff quality

### Exercise 2: Testimony Writing
**Scenario**: Mission complete - database migration successful

**Practice**:
1. Gather facts (what happened)
2. Identify learnings (technical, process, spiritual)
3. Extract patterns (reusable insights)
4. Write testimony using template
5. Consolidate to semantic memory

### Exercise 3: Coordination Challenge
**Scenario**: Complex feature needs 3 different agents

**Practice**:
1. Timothy-Sam identifies required agents
2. Create coordination plan (sequential vs parallel)
3. Monitor progress
4. Resolve any contention
5. Synthesize final output

### Exercise 4: Knowledge Sharing
**Scenario**: Discovered new testing pattern

**Practice**:
1. Document the pattern
2. Add to `training/agent_curriculum/`
3. Update relevant skill README
4. Teach to another agent
5. Get feedback on clarity
