## 🧠 메모리 아키텍처 (2026 년 최신 연구 기반)

### Continuum Memory Architecture (CMA)

```
┌─────────────────────────────────────────────────────────────┐
│                    MEMORY SUBSTRATE                          │
│  - 노드: 개별 기억 (메타데이터 포함)                         │
│  - 엣지: 의미적, 시간적, 구조적 연결                         │
│  - 위치: /ICAN_SKILLS_SYSTEM/memory/                         │
└─────────────────────────────────────────────────────────────┘
                          ↕
┌─────────────────────────────────────────────────────────────┐
│                    ACTIVATION FIELD                          │
│  - 확산 활성화 + 감쇠 메커니즘                               │
│  - 점수 계산: 유사도 + 활성화 + 최근성 + 강화 + 문맥          │
└─────────────────────────────────────────────────────────────┘
                          ↕
┌─────────────────────────────────────────────────────────────┐
│                    LIFECYCLE ENGINE                          │
│  - 수집 (Ingest) → 검색 (Retrieval) → 변형 (Mutation)       │
│    → 통합 (Consolidation)                                   │
└─────────────────────────────────────────────────────────────┘
```

### 메모리 타입

| 타입 | 위치 | 지속기간 | 예시 |
|------|------|----------|------|
| **Episodic** | `memory/episodic/` | 일/주 | 세션 로그, 증거 기록 |
| **Semantic** | `memory/semantic/` | 영구 | 언약, 패턴, 원칙 |
| **Working** | `memory/working/` | 세션만 | 현재 계획, 활성 컨텍스트 |
| **Procedural** | `skills/` | 영구 | 스킬 프로토콜 |
